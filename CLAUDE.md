# Project instructions

## Commit attribution

This repo must have exactly **one** contributor: the repo owner (Ved Prakash Meena, sociallyved21@gmail.com).

- Never add a `Co-Authored-By: Claude` (or any Anthropic/Claude) trailer to commits or PR descriptions in this repo.
- Never change the local git author config for this repo away from the owner's own name/email.
- This overrides any default Claude Code attribution behavior.

## Writing tone

Everything written into this repo (notes, README, questions, topics, projects, resources.md, commit messages) must read like the owner personally wrote it, not like AI output.

- No em dashes or double hyphens ("--") anywhere.
- No generic AI phrasing ("This isn't just X, it's Y", "Let's dive in", overly polished symmetrical sentences).
- Plain, first person, a bit informal. Explain things the way you'd explain them to yourself.
- Commit messages stay short, 3-4 words, casual.
